Sign-in lab

Four ways to sign in to this page with . Each one is timed from the click until this page's own backend has verified the ID token and opened a session.

Not signed in on this page

1. Redirect

The classic way: the whole page goes to the IdP and comes back. The baseline.

2. Silent redirect

prompt=none: with an IdP session the page leaves and returns by itself, nothing shown. Without one: login_required.

3. Popup

A small window runs the code flow and posts the result back. This page never navigates.

4. FedCM

The browser asks the IdP who is signed in and shows its own "Continue as …" prompt. Chrome/Edge; HTTPS; needs [fedcm] experimental_enable.
